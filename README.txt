shittim-logon
=============

将 Windows 11 登录界面的背景替换为实时渲染场景。


应急停用
--------

在登录界面按 Ctrl + Alt + F11。

场景立即关闭并保持停用，重启不恢复，直到重新运行 install.exe，或在设置程序
右上角的通知里点「解除停用」。


安装
----

1. 把压缩包整个解压出来，不要只把 install.exe 拖出来。
2. 右键 install.exe，选择「以管理员身份运行」。
3. 按窗口里的四步走：选安装位置 → 安装前检查 → 安装 → 完成。

安装耗时一至两分钟，主要花在背景图上：它按本机屏幕比例在本地渲染，不使用预制图片。
安装完成后可删除解压出来的这个目录。

只有一个安装包，x64 和 ARM64 通用。安装程序会读取本机架构，自动安装对应的组件，
不需要选版本。


安装前检查
----------

安装程序在动手之前会在这台机器上实际试一次，共十二项。其中三项是真的做一遍：

  文件落地   把 overlay.exe 复制进安装目录，等 1.2 秒后校验 SHA-256 是否一致。
             杀毒软件隔离文件的典型表现就是复制成功、一秒后文件消失。
  启动程序   以挂起状态创建一次进程，不执行任何代码就结束。测的是「能不能启动」。
  计划任务   注册一个 SYSTEM 计划任务、运行、再删除。这是本软件真正的运行方式。

三项做完会把留下的东西全部清掉。

任何一项失败，那一行会直接写清楚该怎么办。已知的三次安装失败都是第三方杀毒软件
造成的，全部在临时关闭之后解决 —— 装完可以再打开。


设置
----

桌面上的「Shittim Logon 设置」，或开始菜单里的同名项，或直接运行安装目录下的 config.exe。
两个快捷方式都是安装时的选项，默认勾选，卸载时一并删除。

场景（含时钟）、角色位置、显示器、系统与高级项都在里面，改完锁屏一次即生效。设置程序不需要
管理员权限，本机任一账户都能改，改动对所有账户生效。

设置仍然是一个文本文件：

    C:\ProgramData\ShittimLogon\scenes.txt

设置程序改的就是它，按行修改，注释和你自己加的内容都会保留，两边可以混用。


卸载
----

Windows 设置 → 应用 → 已安装的应用 → shittim-logon，或运行安装目录下的
uninstall.exe，或在设置程序的「高级」页点「卸载」。

卸载后需重启一次。本软件有一个组件由 Windows 加载在登录界面中，运行期间无法释放，
该文件在下次重启时删除。

设置文件默认保留。如需一并删除，运行 uninstall.exe --purge。


多显示器
--------

场景只显示在一块显示器上，其余显示器保持 Windows 原样（显示系统锁屏图片）。

默认使用主显示器，也就是 Windows 显示密码框的那一块。要换一块，在设置程序的
「屏幕」页里选。

序号顺序由 Windows 决定，不一定从左到右。改为非主显示器后，场景会移动，但密码框
仍由 Windows 画在主显示器上，两者将位于不同屏幕。多数情况下建议保持主显示器。


锁屏背景
--------

安装程序会把当前场景的背景图设为系统锁屏图片。密码界面上场景会把屏幕交还给
Windows，此时显示的即是同一张背景，而不是系统自带壁纸。每次登录场景不同，该图片
随之更新。

Windows 默认会将锁屏图片虚化后作为密码界面背景，本软件保留该行为。如需清晰背景，
在设置程序的「系统」页关掉「密码界面背景模糊」，该项为全局系统设置。

期间「设置 > 个性化 > 锁屏界面」由本软件接管，无法在系统设置中更改，卸载后恢复。


运行条件
--------

仅支持 Windows 11，安装程序会拒绝在 Windows 10 上安装。

Windows 11 家庭版与专业版行为一致，「跳过系统锁屏」在家庭版上同样生效。
1.1.0 及更早版本会在家庭版上提示该功能无效，该提示为误报，现已更正。

若锁屏界面显示正常、而密码界面背景为纯色（通常为纯黑），原因是本机启用了组策略
「显示清晰的登录背景」。该策略并非由本软件设置 —— 它通常来自系统优化脚本、清理
工具或组织的策略模板：

    HKLM\SOFTWARE\Policies\Microsoft\Windows\System
        DisableLogonBackgroundImage

安装前检查会在检测到该策略时明确指出；安装过程会将其关闭并在屏幕上说明，重启后
生效。这是本软件唯一一处会改动、而又并非由自己设置的系统项，卸载时原样恢复。

若安装完成后它再次出现（部分优化工具会定期重新应用策略），重新运行 install.exe
即可。

若本机已启用开机自动登录，则开机时不经过登录界面，场景仅在锁屏时显示。安装前检查
会指出这一点。

重启后的第一次登录，默认关闭了 Windows 的「重启后自动登录并锁定」
（设置程序「系统」页的「允许重启后自动登录」）。不关掉它，重启后你面对的密码界面
其实是「解锁」而不是「登录」，Windows 不会记录认证事件，开场动画在那一次不会播放。
代价是系统更新的收尾工作改为在你登录时进行。想要 Windows 原本的行为，把这一项打开。
卸载时会自动还原。


登录方式
--------

场景不接收键盘输入，不改变现有登录方式。密码框与右下角系统按钮出现后，那一区域
交由 Windows 接管，可正常点击。

场景处于待机（尚未有人操作）时，屏幕全部归场景，此时点击不会落到下层。任何按键或
鼠标移动都会唤醒场景，约三秒后恢复。

PIN 登录正常。指纹与人脸登录可正常使用，但默认不触发动画：动画由按键触发，而这两种
方式不产生按键。设置程序「系统」页的「实验性功能」可改变此行为，该选项未在真实硬件
上验证过。


故障排除
--------

先打开设置程序的「诊断」页：启动任务、常驻进程、凭据提供程序、应急停用状态都在
那一页，写明了每一项不正常时是什么后果。

日志位于 C:\ProgramData\ShittimLogon\logs\，不包含任何个人信息，可直接提供。
其中 install.log 是安装过程的完整记录，包括安装前检查的每一项结果。

也可以在命令行运行 install.exe --verify 重新校验一次已安装的内容。
