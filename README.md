## 项目简介

**shittim-logon** 是一款 Windows 11 锁屏美化工具，将《蔚蓝档案》中「什亭之箱」的场景与角色 **普拉娜** 与 **阿罗娜** 以 Spine 实时动画的形式呈现在登录界面上。当检测到有人到来时，普拉娜与阿罗娜会播放欢迎动画。

完整的安装与使用教程请观看 B 站视频：

 [「什亭之箱」Windows 锁屏美化完整安装教程](https://www.bilibili.com/video/BV1v3Ys6mEEv/)

---

## 效果说明

安装并配置后，Windows 11 登录界面会发生以下变化：

- **背景替换**：登录界面的壁纸被替换为「什亭之箱」场景的静态画面。
- **实时角色**：场景中会出现 Spine 骨骼角色 **普拉娜** 与 **阿罗娜**，以实时动画形式呈现。无人操作时，角色处于待机状态。
- **到来响应**：当检测到用户到来（按键、移动鼠标、触摸等输入），角色会播放欢迎动画，触发迅速。
- **登录框保留**：Windows 原生的密码输入框和登录按钮仍然显示在角色上方，可以正常输入密码登录。
- **无缝融合**：背景与实时角色之间没有可见接缝。
- **锁屏唤醒**：从锁屏界面唤醒后，角色动画会随之触发，仿佛角色一直在等待。

> 由于登录界面无法被普通截图工具截取，效果只能在实际登录界面中看到。

## 紧急恢复

如果在登录界面遇到问题（例如无法输入密码），请在登录屏上按下：

```
Ctrl + Alt + F11
```

这将临时禁用大部分功能，并留下标记使其保持关闭，以便正常登录系统。
